## 必答的三个问题（要点）

**1）为什么先做 HTML 再做 Vue？**
HTML 阶段把「请求 → 表单 → 查库 → 渲染」这条链路走通，理解 HTTP、表单、SQL、渲染；
Vue 阶段才把「数据驱动视图」叠上去，接口不变、只换渲染层。先懂机制再用框架，出问题才知道断在哪。

**2）控制器、模型、接口、前端各干什么？**
- 路由：URL → 控制器方法（`route/app.php`）
- 控制器：参数校验、权限、业务编排（`app/controller/*.php`）
- 模型：表映射与查询（`think\Model`，如 `ArticleModel`，禁止业务层用 `Db::`）
- 接口：统一 JSON `{code,msg,data}`（`ApiBase::ok/fail`）
- 前端：只负责调接口 + 渲染（`service/request.js` 统一 BASE 与 `X-Token`）

**3）点赞为什么要登录、怎么防重复？**
登录才能把赞记到具体用户（`article_likes.user_id`），否则无法去重也无法「取消赞」；
防重复靠两层：控制器先查是否已赞（返回 `code=1004`），数据库再加 `UNIQUE(article_id,user_id)` 兜底。
